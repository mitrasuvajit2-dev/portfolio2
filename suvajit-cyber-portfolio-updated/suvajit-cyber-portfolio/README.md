# Suvajit Mitra — Cyber Security Portfolio

A responsive hacker-style personal portfolio built with HTML, CSS and JavaScript.

## Included
- Animated secure-terminal/login intro
- Profile photo
- Cybersecurity-inspired matrix background
- Skills, experience and education sections
- GitHub and email contact buttons
- Mobile-friendly responsive layout
- Green/cyan colour mode switch
- Typing animation

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `profile.jpg`.
3. Go to **Settings → Pages**.
4. Select the main branch and root folder.
5. Save and open the generated GitHub Pages URL.
